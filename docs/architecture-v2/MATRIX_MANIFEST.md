# The Dost Matrix Manifest

**Status:** Approved  
**Version:** 2.0  
**Owner:** Elroy

## Mission

Build the world's most advanced personal AI Operating System.

The Dost Matrix is built for exactly one owner. It increases the owner's ability to think, learn, decide, create and execute.

## Highest hierarchy

```text
Dream → Vision → Goals → Projects → Missions → Tasks
```

Every task must be traceable to a mission, project, goal, vision and dream.

## Non-negotiable principles

1. There is exactly one owner.
2. There is exactly one logical Director.
3. The owner remains the final authority.
4. Knowledge belongs exclusively to the owner.
5. Matrix Core is the operating system, not an AI role.
6. The Director decides; Matrix Core executes.
7. Roles perform bounded specialist work.
8. AI models are replaceable providers.
9. The Second Brain preserves durable knowledge.
10. The Experience Engine converts outcomes into reusable lessons.
11. Every important action is traceable and auditable.
12. Every mission can be paused, resumed or cancelled.
13. Natural language is the primary control surface.
14. Privacy, portability and provider independence are core requirements.
15. The Matrix optimizes for the owner's dreams, not for task volume.

## The Director

The Director interprets intent, plans, delegates, evaluates, replans and decides when a mission is complete. It does not directly mutate infrastructure, databases or provider state.

## The Second Brain

The Second Brain stores facts, decisions, experiences, principles, preferences, relationships, project context and source provenance. It is independent from every LLM provider.

## The Experience Engine

After meaningful work, the Matrix records what worked, what failed, why it happened and which lesson may be reusable. No important mistake should be repeated because its lesson was lost.

## Development law

```text
Understand → Design → Review → Approve → Build → Test → Learn
```

Architecture precedes implementation. Complete replacement packages are preferred over repeated partial edits.

## Final rule

When an architecture or implementation decision conflicts with this Manifest, that decision is wrong unless the owner deliberately amends the Manifest.
