# ADR-001-ONE_OWNER

## Titel

Eén Eigenaar

## Status

Geaccepteerd

## Context

The Dost Matrix vereist een expliciet besluit om architecturale ambiguïteit te voorkomen.

## Besluit

The Dost Matrix wordt ontworpen voor precies één Eigenaar.

## Uitwerking en gevolgen

Multi-tenancy wordt niet opgenomen. Alle gegevens, kennis en bevoegdheden zijn aan dezelfde Eigenaar gekoppeld.

Dit besluit is normatief voor alle documenten in `docs/architecture/`.
