# ADR-006-ROLE_COMMUNICATION

## Titel

Rolcommunicatie via de Core

## Status

Geaccepteerd

## Context

The Dost Matrix vereist een expliciet besluit om architecturale ambiguïteit te voorkomen.

## Besluit

AI-rollen communiceren via taken, events, artefacten en gecontroleerd geheugen.

## Uitwerking en gevolgen

Directe verborgen rol-naar-rol toestand is niet toegestaan.

Dit besluit is normatief voor alle documenten in `docs/architecture/`.
