# ADR-002-MATRIX_CORE_IS_OS

## Titel

Matrix Core is het besturingssysteem

## Status

Geaccepteerd

## Context

The Dost Matrix vereist een expliciet besluit om architecturale ambiguïteit te voorkomen.

## Besluit

De Matrix Core is een bestuurlijke laag en geen AI-rol.

## Uitwerking en gevolgen

Redenering ligt bij AI-rollen; de Core beheert toestand, rechten, events en uitvoering.

Dit besluit is normatief voor alle documenten in `docs/architecture/`.
