# Geheugenmodel

## Typen

- **Werkgeheugen:** tijdelijke context voor een actieve taak.
- **Episodisch geheugen:** samenvattingen van missies, gebeurtenissen, fouten en beslissingen.
- **Semantisch geheugen:** geconsolideerde feiten, voorkeuren en concepten.
- **Procedureel geheugen:** herbruikbare werkwijzen en checklists.

## Schrijfbeleid

AI-rollen schrijven niet onbeperkt rechtstreeks naar langetermijngeheugen. De Memory Coordinator en waar nodig de Chronicler valideren kandidaten.

Een geheugenrecord bevat type, inhoud, scope, bronverwijzingen, confidence, geldigheid, classificatie, maker en reviewdatum.

Dubbele herinneringen mogen worden geconsolideerd zonder bronverlies. Conflicten blijven expliciet zichtbaar. De Eigenaar kan geheugen verwijderen of intrekken. Verouderde herinneringen worden niet stilzwijgend gebruikt.
