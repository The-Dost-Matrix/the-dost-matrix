# Architectuurdocumentatie — The Dost Matrix

Deze map bevat de normatieve architectuurbasis van The Dost Matrix: een persoonlijk AI Operating System voor precies één Eigenaar.

## Documenten

- `THE_DOST_MATRIX_PRINCIPLES.md`: onveranderlijke principes.
- `THE_DOST_MATRIX_ARCHITECTURE.md`: conceptuele architectuur.
- `TECHNICAL_ARCHITECTURE.md`: huidige implementatiearchitectuur.
- `DATA_MODEL.md`: kernentiteiten en relaties.
- `EVENT_MODEL.md`: gebeurtenissen en berichtstromen.
- `AGENT_SPECIFICATIONS.md`: AI-rollen.
- `SECURITY_MODEL.md`: beveiliging en vertrouwen.
- `SECOND_BRAIN.md`: persoonlijke kennislaag.
- `MISSION_ENGINE.md`: missielevenscyclus.
- `MEMORY_MODEL.md`: geheugen.
- `PERMISSION_MODEL.md`: bevoegdheden en goedkeuringen.
- `ROLE_MODEL.md`: rollen en runtime-instanties.
- `ORCHESTRATION_MODEL.md`: planning en uitvoering.
- `GLOSSARY.md`: bindende terminologie.
- `adr/`: Architecture Decision Records.

## Regels

De woorden **MOET**, **MAG NIET**, **BEHOORT**, **MAG** en **KAN** zijn normatief. Fundamentele wijzigingen vereisen een nieuw ADR. De conceptuele architectuur blijft technologie-onafhankelijk; implementatietechnologie staat uitsluitend in `TECHNICAL_ARCHITECTURE.md`.
