# The Dost Matrix — DNA

## Founder
Elroy Dost

## Purpose
The Dost Matrix is het digitale besturingssysteem voor Elroy's werkzaamheden,
ondernemingen, producten en toekomstige AI-agents.

## Principles

1. Voice First
2. Context Never Lost
3. Human Approval
4. Modular Everything
5. Beautiful by Default
6. Model Independent
7. Automation Last, Understanding First
8. Least Privilege
9. Audit Everything Important
10. Reversible by Default

## Foundation boundary

Version 0.2 may:
- authenticate Elroy;
- create and read Elroy's own missions;
- append audit events;
- show realtime state.

Version 0.2 may not:
- deploy production code;
- spend money;
- access customer data;
- finalize legal material;
- delete audit history;
- use administrative credentials in the browser.
