# Beveiligingsbeleid

Dank je wel voor je interesse in het veilig houden van dit project. We nemen de beveiliging van onze software serieus en waarderen het als beveiligingsproblemen op een verantwoorde manier worden gemeld.

## Een beveiligingsprobleem melden

**Meld beveiligingsproblemen alsjeblieft niet via publieke GitHub issues, pull requests of discussies.** Openbare meldingen kunnen kwaadwillenden de kans geven om een kwetsbaarheid te misbruiken voordat er een oplossing beschikbaar is.

Meld een beveiligingsprobleem in plaats daarvan privé via e-mail naar:

**security@dostmatrix.dev**

Neem in je melding, indien mogelijk, de volgende informatie op:

- Een duidelijke beschrijving van het probleem en de mogelijke impact.
- Stappen om het probleem te reproduceren (proof-of-concept code is welkom).
- De versie of commit van de repository waarin je het probleem hebt gevonden.
- Eventuele voorgestelde mitigaties of oplossingen (optioneel).

## Wat je kunt verwachten

- We bevestigen de ontvangst van je melding binnen **2 werkdagen**.
- We beoordelen het gerapporteerde probleem en houden je op de hoogte van de voortgang.
- Zodra er een oplossing beschikbaar is, coördineren we met jou over een verantwoorde openbaarmaking (responsible disclosure), inclusief eventuele credits als je dat wenst.
- We vragen je om details over het probleem vertrouwelijk te houden totdat er een fix is uitgebracht.

## Reikwijdte

Dit beleid heeft betrekking op de broncode in deze repository. Voor problemen met externe diensten, infrastructuur of afhankelijkheden van derden verwijzen we je door naar de betreffende beheerders.

We waarderen je hulp om dit project en zijn gebruikers veilig te houden.
