# Beveiligingsbeleid

Dank je wel voor je interesse in het verbeteren van de beveiliging van dit project. We nemen beveiligingsproblemen serieus en stellen het op prijs als je verantwoordelijk omgaat met het melden ervan.

## Een beveiligingsprobleem melden

**Meld beveiligingsproblemen alsjeblieft niet via een publieke GitHub issue.** Publieke meldingen kunnen kwetsbaarheden blootleggen voordat er een oplossing beschikbaar is, wat andere gebruikers onnodig risico laat lopen.

Meld een beveiligingsprobleem in plaats daarvan privé via e-mail:

**security@example.com**

Vermeld in je melding indien mogelijk:

- Een duidelijke omschrijving van het probleem en de mogelijke impact.
- Stappen om het probleem te reproduceren (proof-of-concept, indien beschikbaar).
- De versie(s) of commit(s) van de code waarin je het probleem hebt aangetroffen.
- Eventuele suggesties voor een oplossing of mitigatie.

## Wat je kunt verwachten

- We bevestigen de ontvangst van je melding binnen **48 uur**.
- We onderzoeken het gemelde probleem en houden je op de hoogte van de voortgang.
- Zodra het probleem is opgelost, informeren we je en overleggen we graag over een gepaste manier en timing om het probleem (en eventueel jouw bijdrage) publiekelijk te erkennen, als je dat wenst.

## Scope

Dit beleid heeft betrekking op beveiligingsproblemen in de code en configuratie van deze repository. Voor vragen die geen betrekking hebben op beveiliging kun je gewoon een reguliere GitHub issue openen.

Bedankt voor het helpen houden van dit project veilig voor iedereen.
